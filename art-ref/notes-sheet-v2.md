## 2. 用户六条 → 可验收指标

| 优先级 | 用户意见 | 可验收的量化目标 |
| --- | --- | --- |
| P0 | 建筑轮廓太方正，主殿与钟楼挤在一起 | 主堂平面必须是十字形（含后殿体量）；**钟楼与主堂包围盒不重叠，净距 ≥ 3 m**；正视图中塔顶 x 位置偏离中轴 ≥ 7 m |
| P0 | 入口缺仪式感，门像贴片 | 门洞**真实穿透**（进深 ≥ 1.2 m）；**3 层递进拱**（narthex 内凹）；台阶 ≥ 5 级；门两侧壁灯座各 1 |
| P0 | 雪山氛围不足 | 远山 3 层：迎光面比背光面亮 15–25%、最远层有雪线、山脚有 2 层横向云雾带；地面 100% 覆盖薄雪（草地仅从雪下露出斑块） |
| P1 | 材质重复感 | 石块尺寸变异 ≥ 3 档、每 4 块 1 处风化/缺角、墙脚 20% 面积苔藓、上表面 100% 积雪 |
| P1 | 光照平 | 主光斜射仰角 ≤ 25°；窗内暖光 ≥ 4 处；火盆 ≥ 2 处（含粒子）；可见体积光 |
| P1 | 缺场景引导 | 石阶/围墙/旗帜形成连续指向正门的动线；人物屏高 28–32 px（远景）/ 120–170 px（近景） |

## 3. 视觉语言统一（最关键，独立成项）

四个元素必须在**像素密度、色板、光照模型**上同源：

| 元素 | 现状 | 目标 |
| --- | --- | --- |
| 草地 | 写实低模、平绿 | 改用**像素贴片/贴图**，色板取设定画"环境(雪/枯草)"，与建筑共用同一套光照参数 |
| 远山 | 几何剪影 | 分 3 层、带迎光/背光面与雪线；不再用纯色填充 |
| 建筑 | 重复贴图 | 砌块变异 + 风化 + 苔藓 + 积雪层（见上表 P1） |
| 人物 | 简化色块 | 像素密度与草地贴图一致（32 PPU），受同一主光 + 环境光 |

**统一判据**：把画面降到 480×270 再放大看，草、山、建筑、人物的"颗粒大小"应大致一致；不一致即为语言分裂。
