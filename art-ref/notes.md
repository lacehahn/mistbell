# Gergeti 概念图规格（2026-11-02 用户提供参考）

参考图：`concept-gergeti-sunny.jpg`（晴日逆光版本）

> 性质：写实绘制向概念图，**不是**像素风。取其构图／光影／色板／建筑体量做 HD-2D 重构；
> 其"晴日无雾"与设计中的"云雾揭示"不冲突——揭示段保留雾，到达后常态用这套晴日光照。

## 1. 构图（可量化）

| 项 | 参考值 | 落进引擎的含义 |
| --- | --- | --- |
| 教堂位置 | 画面横向 30–40%、纵向顶部 25–35% | 相机 target 略高于教堂中部，教堂偏左构图 |
| 钟楼 | **独立体量**，主教堂右侧 12–15 m，同石色 | 不能塞进主教堂体块里，要独立 GameObject |
| 遗迹长屋 | 主教堂右下，带 3–4 个拱形窗洞 | 增加"废墟感"与近读纵深，MVP 可做低模 |
| 主路 | 从画面底部中央蜿蜒至教堂，宽 2.5–3 m | 石板路，S 形上行，是视线引导 |
| 前景 | 左下失焦野花＋岩石，占画面 15% | 需要前景遮挡物 + 近景景深 |
| 雪山 | 占画面高度 **40%**，分 2–3 层递减对比 | 远景天空盒/背板必须有山，否则没有压迫感 |
| 人物 | 画面高度 **~8%**（很小） | 与我们 172 px / 1080 ≈ 16% 冲突 → **按参考图缩小到约 90–110 px**，或拉远相机 |

## 2. 光照

- 主光：左上 30–40° 仰角逆光，强度高，色温偏暖（约 5200 K 的日落前感）
- 环形光：草地边缘、石墙顶沿出现暖色轮廓（rim）
- 阴影：偏冷蓝，不加深灰
- god rays：从左上向左下放射，3–5 条可见光柱，仅在有遮挡处出现

## 3. 色板

| 用途 | 参考色 |
| --- | --- |
| 草地亮部 / 暗部 | `#C8D96B` / `#5E7A2E` |
| 砂岩墙 | `#C6A882` / `#8F7355` |

| 野花点缀 | `#9B7BC4` / `#E8D06B` |
| 阴影 | `#2B3A4A` |

## 4. 空气与纵深

- 山谷薄云：2–3 层半透明白蓝，横向拉伸，贴在山腰
- 远山对比度逐层下降（近山明确、远山发白），这是纵深的主要手段
- 画面整体轻微雾感（不是浓雾），近景清晰

## 5. 与我们现有 spike 的差距（待修）

1. 角色悬空（未按地形吸附）
2. 没有远山背景板 → 画面像放在绿板子上
3. 没有石板路、钟楼、遗迹长屋
4. 没有 god rays、没有暖色 rim
5. 调色偏灰白，缺参考图的饱和与明暗对比
