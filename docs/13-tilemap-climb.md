# Tilemap 版 2D 攀爬（分支：feature/tilemap-climb）

## 为什么单开分支
现在 main 上的 2D 攀爬是**贴图图层合成**（一张 S 形路带图 + 上/下坡面 + 树 + 视差），
能看，但「路」不是画出来的引导线——走两步就丢了方向。要做出《歧路旅人》那种地图感，
需要改成 **tilemap 绘制**：路面、路肩、崖边、雪地都是可拼接的地图块，由数据决定走向。

优点是可控、可扩展、不依赖单张大图；代价是要重画一套 tile（约 20–30 张），并写一个绘制器。

## 起点
- 分支从 `main@d225461`（tag `checkpoint-path-read`）拉出
- 现有 2D 场景骨架、走位、转场、相机逻辑**全部保留**
- 只替换「地形绘制与碰撞」这一层

## Tile 规格（草案）
- tile 尺寸 **16×16 逻辑像素**（×4 = 64 px 屏幕）
- 需要 4 类：
  1. **路面**：直/左上弯/右上弯/左下弯/右下弯/十字（6 张）
  2. **路肩**：左雪肩/右雪肩/内弯雪肩/外弯雪肩（4 张）
  3. **崖边**：左崖/右崖/崖角/雪檐（4 张）
  4. **地面填充**：雪地 3 变体 + 岩石 2 变体（5 张）
- 全部 16×16、横向纵向都能拼、色板统一（雪 `#EDF3F8`，石 `#7B766E`，`b* +6`）

## 绘制器（代码侧）
- 数据用 ASCII 地图（每行一个字符串）或 `int[]`，例如：
  ```
  ...PPPP....
  ..PP..PP...
  .PP....PP..
  ```
- 按字符查表放 tile，支持 4 向自动接缝（autotile）：
  判断邻居决定用直/弯/丁字 tile
- 碰撞与贴地沿用现有路线数据（不改走位逻辑，只让视觉与碰撞共用同一份路径）

## 验收
- `[TILEMAP] tiles=… autotile_ok=true path_follows_data=true`
- 屏幕上能看到**连续、有拐弯引导**的石路，至少 2 次折返 + 竖向石阶段
- 全程 45–55 s、转场 `ok`、进 3D `bad=0`
- 与 main 的 3D 部分完全隔离（分支不改 3D）

## 风险
- 重画 tile 需要你出图（约 20 张），或先用程序化色块占位跑通结构
- 如果不满意，直接回 main 的 `checkpoint-path-read`，不影响已验收版本
