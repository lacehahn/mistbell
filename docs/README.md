# Sacred Sites 文档索引

> 项目暂用代号「Sacred Sites（圣地）」，正式名称未定。当前阶段只产出设计与技术文档，尚未创建工程、代码或资产。

## 1. 一页速览

以「朝圣」为核心的 HD-2D 探索叙事 RPG：从山脚小镇步行上行，经历针叶林、草甸、裸岩与云层，在云雾散开时看见古老教堂；抵达后观察建筑、阅读带出处的介绍、收集札记，再自主离开。完整首地点采用无战斗方案，角色扮演来自旅人的步行与观察选择。

首个地点固定为格鲁吉亚 Stepantsminda（Kazbegi）镇上方的圣三一教堂（Gergeti Trinity Church），14 世纪格鲁吉亚东正教教堂，项目海拔基线约 2170 m，背景卡兹别克山基线 5033 m。事实依据和概数差异见 [愿景：事实与重构](00-vision.md#2-事实重构与设计数值)，不以游戏场景提供现实导航。

| 项目 | 完整 Gergeti | MVP | 取舍理由 |
| --- | --- | --- | --- |
| 核心范围 | 6 Zone、10 POI、外部与内部探索 | 同一上行链路，3 个外部 POI：P04 钟楼、P05 门廊外侧、P06 外墙石材 | 先验证抵达与阅读，内部须补资料 |
| 时长 | 20–30 分钟，参考 25 分钟 | 12–16 分钟，参考 14 分钟 | 基于步行、每条约 45 秒阅读与观察停留，不设置限时 |
| 场景尺度 | 参考走线约 660 m，含广场／内部约 100 m | 参考走线约 600 m，含广场外部约 40 m | 路线平面包络约 420×220 m、游戏几何累计抬升约 42 m；叙事海拔上升约 420 m，明确艺术化压缩 |
| 关键演出 | 18 秒云雾揭示＋14 秒广场抵达衔接 | 同规格，均可跳过、暂停和减少镜头移动 | 保留体验核心，不靠长影片替代步行 |
| 视觉基线 | 像素角色／小物件＋高分辨率 3D、移轴感、光雾、Bloom、调色 | 4 方向角色 48 帧，教堂外壳与钟楼 LOD0 共 ≤80000 三角面 | 64×80 px 画布、32 PPU、1.75 m 身高；完整角色为 8 方向 96 帧 |
| 技术建议 | Unity 6 LTS＋URP、Blender→FBX、外部 JSON 内容源 | 同一架构，不接联网与商店 SDK | 技术推荐明确，版本与人力仍须在实现前确认 |
| 平台目标 | Windows 优先，macOS 用于开发与试玩 | Windows 1080p 中画质平均 ≥60 fps；M1／16 GB Mac 低画质 ≥30 fps | 是未来目标，尚无性能实测，硬件与分位数口径见技术文档 |
| 计划投入 | 完整扩展另估 | 2 人各每周 20 小时、8 周、320 人时，其中 64 人时缓冲 | 为待确认的人力假设，单人同等周工时约需 16 周 |

不做战斗、养成、生存、开放世界、完整城镇生活、联网和强制全收集；阅读与收录不是离开的条件。所有实现数值均为制作建议，依据小团队、单路线、受控相机假设；它们不代表测绘、实测或已批准开发。下一阶段建议先用 M1 灰盒验证路线、角色遮挡、相机与 Windows 构建，当前交付仍仅限文档。
