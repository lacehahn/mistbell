## 怎么跑

```bash
cd ~/workspace/mistbell
caffeinate -dimu open -n -a "$PWD/spike/project/Builds/Mac/Mistbell.app"
```
（`caffeinate` 必须加：显示器一睡，播放器主循环会停。）

## 操作

| 键 | 作用 |
|---|---|
| `W A S D` | 移动（贴着地形走，可上台阶） |
| `Shift` | 疾跑 |
| `E` | 查看 / 关闭景点介绍（靠近会有「按 E 查看」） |
| `F` | 室内抬头看穹顶 |
| `Esc` | 设置（音量 / 中文 / English / 双语 / 札记 / 退出） |
| `C` / `N` | 有存档时：继续 / 重新开始 |

## 建议试这 6 件事

1. **从出生点一路爬到台地**：约 210 m、爬升 27 m，中途 2 个野外景点；注意雪地脚印会跟着你走
2. **走到教堂前看显现**：20→80 m 处有云雾渐开 + 钟声一次的机制
3. **绕到右侧钟楼**（上次被挡住的那条路）：`gergeti_p02` 应该是能走到的
4. **进正门**：门会自动开，室内有长椅/烛台/圣像屏；按 `F` 抬头看鼓座 12 窗穹顶
5. **打开 3 个景点**：每个都是中英双语；再按 `Esc` → `札记 Notes`，看已读/未读区分
6. **退出再进**：会自动续到上次位置（`C` 继续 / `N` 重开，3 秒自动继续）
