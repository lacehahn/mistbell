# HD-2D 在 Unity 里的开发指南（基于 Mistbell 实测）

> 这份不是教程的复述，是本项目真做出来之后回写的：哪些数字是硬门槛、哪些坑会静默失败、
> 哪些"看起来对"其实已经错了。所有数值都来自实测（`spike/PROGRESS.md` 可追溯）。

---

## 0. 一句话定义

HD-2D = **像素角色 + 3D 场景 + 电影化后处理**，四要素（草/山/建筑/人）在**像素密度、色板、光照**上同源。
判据只有一个，能一句话验完：

> 把画面缩到 **480×270** 再最近邻放大 4 倍，画面里所有元素的**颗粒大小必须一致**。

颗粒不一致 ＝ 要么角色贴图分辨率不匹配，要么某处用了双线性采样，要么贴图世界密度不统一。

## 1. 渲染管线骨架（URP）

| 组件 | 取值 | 说明 |
|---|---|---|
| 引擎 | Unity 6.3 LTS + URP 17 | URP 的 Volume 后处理是 HD-2D 的一半功劳 |
| 主光 | Directional，仰角 **20–30°**，色 `#FFD9A8`~`#FFE0B8`，强度 **1.6–2.0** | 低角度才有长影子与侧光面 |
| 环境光 | `ambientSky #8C97A6` / `equator #7E8794` / `ground #6B6E73` | **只做填充**，贡献 ≤ 受光面 35% |
| 后处理 | ACES、Bloom 0.9/0.75/0.72、DoF、ColorAdj −0.15EV、对比 14、饱和 −6、暗角 0.16、颗粒 0.18 | 参数可以调，顺序别乱 |
| 相机 | 玩法 FOV **45–50**，低机位 | 靠**距离**控制角色占屏，不靠 FOV |

**血泪规则**：环境光一旦变强，画面会整体发灰发冷、对比被拉平——因为环境光没有方向，
它会均匀抬高所有背光面。判断方法：看背光面是不是"有明度但没方向"。救法是把主光抬回 1.8–2.0，
环境光砍到 35% 以下，再给朝下面法线一个下限 `max(SampleSH(n), 0.10)`，避免死黑但不提亮全局。

## 2. 相机与"微缩感"

HD-2D 的移轴感来自**景深**，不是来自后期模糊：

- **必须用 Gaussian 模式的 DoF**（`focusDistance / gaussianStart / gaussianEnd / gaussianMaxRadius`）。
  URP 的 Bokeh 模式里 `aperture / focalLength` **只有相机开启 Physical Camera 才生效**，
  没开就等于没有景深——这是最容易静默失败的一项。
- **焦点跟随主角**：每帧 `focus = 相机到角色距离`，`start = 0.55×focus`，`end = 3×focus`。
  写死焦点会在走近/走远时把主角虚掉。
- 参考图/验收图这类"看材质看构图"的机位要**关闭景深**，否则你没法判断材质。

相机机位（第三人称近景）：

```
FollowOffset = (0, 2.0~2.2, -11.5)   // 距离 11.5 m
LookHeight   = 1.15~1.25             // 看向人物胸口偏上
FOV          = 48
```

角色占屏 **13–16%**（1080p 约 140–170 px）是舒服的区间；超过 25% 就会挡场景，低于 10% 就认不出角色。

## 3. 资产流程（用户定稿的最佳实践）

> **先生成 3D 模型 → 再针对模型生成贴图 → 世界投影平铺/实例化**

顺序反了必翻车。具体：

1. **3D 模型**（Blender 程序化脚本 / 手工）
   - 形体先定：比例、倒角（≥2 段）、关键凹龛进深（≥0.05 m）、布料褶（起伏 0.03 m 才看得见）
   - 三角面：单体 **3k–9k** 足够；教堂主体 7 万面、祭坛 8.8k 面
2. **贴图**（模型定稿后再做）
   - 手绘扁平笔触，**三阶明度**，不要写实照片、不要照片缩小
   - 尺寸 1024²/1254²，尽量**无缝**（实测接缝差 ≤ 内部基线 2 倍以内可接受）
   - 像素风元素（图标）用**逻辑像素**绘制再整数倍最近邻放大：72×110 → 512×784，Point 采样、关 mipmap
3. **铺贴**
   - 世界投影 **1.35–2.4 m 一铺**（石板/砖），两档尺度 + 随机旋转叠合压掉接缝
   - 沿高度/距离做**混合**（例：山脚裸石 → 山顶雪压，8 m 过渡带）

**贴图尺度是最常错的一项**：贴图按 2.4 m 铺时，图上那些 1–2 m 的裂缝会读成"路裂开了"；
收到 1.35 m 才会读成"一块块石板"。判据：缩到 480×270 后能数出石板块，且不是裂缝网。

## 4. 像素角色（Billboard）

- 用 **Quad + 自定义 shader**，世界高度由 `_ScaleY` 控制，`_ScaleX = _ScaleY × 帧宽/帧高`（等比，别拉长）
- 采样：**Point、关 mipmap、aniso 1**；否则放大后边缘发糊
- 2 等身（头占身高一半）的画法**不要硬撑真人身高**：1.7 m 配 2 等身会得到 0.85 m 的头，
  站在椅子旁就是个"大头木偶"。缩到 **1.5 m 左右**，让头大变成风格
- **碰撞体高度必须跟着改**（我们踩过：模型 1.36 m、碰撞体 1.7 m，头顶穿梁却测不出来）
- 与地面分离：加**接触阴影贴片**（0.24×0.18 m、alpha 0.16–0.22），否则角色像浮着

## 5. 光照落地清单（室内/室外都要过这几条）

| 判据 | 门槛 | 怎么量 |
|---|---|---|
| 受光/背光 L* 差 | ≥ 12 | 截图裁两块算 CIELAB |
| 天花板/受光墙 L* 差 | ≥ 14（顶更暗） | 同上 |
| 色相 | `b*` 受光 8–11、背光 ≤ 8 | 防止整幅泛黄"砂岩仓库" |
| 暗部不死黑 | 背光面 L* ≥ 18 | 靠 `max(SH, 0.10)` 下限 |
| 自发光别乱加 | 地板自发光 0.16 会把整片地面打成白色 | 用光照出亮，不要用自发光"调亮" |

**关键教训**：材质改了画面不变，先确认**改的是不是画的那个材质**。
Unity 里室内物件常常是**序列化进场景的材质副本**（场景对 `.mat` 资产的 GUID 引用数为 0），
改资产文件无效，必须按 `场景重建 → 改资产 → 出包` 的顺序，否则会被覆盖。

## 6. 远景与雾

- 远山用**三层像素山 Quad**（900/1300/1800 m，宽 1049/1516/2099 m），不用 3D 山脊
- 雾按层递减：`MistHaze 0.12/0.26/0.42/0.58`；山体亮部 `+6~8%` 让它在白雾里有对比
- **"雾里能看见山"与"远处教堂被雾吃掉"是互相拉扯的**：
  用"80 m 处教堂视高 ≤30% 且与雾对比 ≤0.18"这类**双距离构图判据**，不要用"远近视高比"这种单一比值
- 天空球 UV 接缝会造成画面竖暗带：`rotation.y` 转 37° 可避开视锥

## 7. 性能

- **合批优先**：把同类小物件合成单批次。实测 drawcall 从 **6517 → 174**（−97%）
- 围栏这类重复构件用 **一段一跨的模型 + 实例化**（183 段合并成 **1 个批次**，每段 64–120 tris）
- 室内点光 ≤ 20 盏、阴影只给主光；`ForcePixel` 只给需要的灯
- 目标：室外 `fps ≥ 200`、台地 `drawcall ≤ 330`、室内 `≤ 280`

## 8. 自动化验收（没有这套就等着被静默失败骗）

1. **截图必须走播放器**：`open -n -a <app> --args …`（直接 exec 二进制时窗口非激活、Unity 不渲染）
   ＋ 全程 `caffeinate -dimu`（显示器休眠会停主循环）＋ 截图前预热 ≥1 s 实时
2. **每个改动都有判据日志**：`[LIGHT] nave=0.0331 wall=0.0378 b=11.0`、`[PATH_W] width=2.1 radius=21.2`
3. **失败要计入 bad**：我们有过 `[REVEAL] gate=FAIL` 但演示脚本 `bad=0` 的静默失败，
   它静静错了两天，直到逐条 grep 才发现
4. **判据要成对**：只看"亮度 ≥ 阈值"会逼出过曝；只看"视高比"会逼出把山埋回雾里
5. **量测口径写进任务书**：贴图均值 vs 渲染后均值差很多（同一个材质 55.7 vs 25.3），不写清就会各说各话

## 9. 十二个真实踩过的坑

1. 环境光变主光源 → 整幅发灰、对比拉平
2. Bokeh DoF 没开 Physical Camera → 景深完全不生效
3. 材质资产不被场景引用（GUID 引用 0）→ 改 `.mat` 不生效
4. 自发光当地面亮度调节 → 地面整片发白
5. alpha 未生效的草簇 → 雪地上几十个"黑色梳子"
6. 原子化小物件（185 柱 + 366 杆）→ drawcall 爆、观感像护栏
7. 贴图按 2.4 m 铺 → 裂缝读成"路裂开"
8. 横杆整根穿过立柱 → 近景一眼假（必须嵌入 3 cm + 一段一跨共享柱）
9. 角色 2 等身硬撑 1.7 m → 大头木偶；碰撞体不同步 → 头顶穿梁
10. 长椅靠背建在 +Z 侧而祭坛也在 +Z → 整排人背对祭坛
11. 天空球 UV 接缝 → 画面竖暗带
12. 存档路径随 `companyName/bundleId` 变 → 存档"消失"（写死目录 + 迁移旧文件）

## 10. 推荐的动手顺序

1. 定**像素密度判据**（480×270 检验）与**相机占屏比**（13–16%）
2. 搭**光照骨架**（主光低角度 + 环境光填充 ≤35% + SH 下限）
3. 做**景深与焦点跟随**（Gaussian，别碰 Bokeh）
4. 按"模型 → 贴图 → 世界投影"做**一套资产**跑通（教堂/石板路各一）
5. 用**自动化演示 + 判据日志**把这些数值钉死，任何改动都跑一遍
6. 之后才是内容量：每个新物件重复第 4 步，数值复用前一步的判据
