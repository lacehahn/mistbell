只做一件事：**把材质风格拉齐到《歧路旅人》HD-2D 的手绘像素质感**，并产出可复现的"程序化材质生成器"。不改玩法/相机/关卡布局/UI。

用户原话：「让画面风格符合八方旅人的风格，我需要 codex 生成材质」。当前问题不是缺细节，而是**四种元素的视觉语言不同源**：石材是照片式砌块 + PBR 平滑高光，雪地是噪声，木头是纯色，人物是像素图 → 缩到 480×270 后颗粒大小完全不一致。

## 一、总目标（可判定）

把画面缩到 **480×270 再放大 4 倍**（最近邻）时：
1. 任意两个元素的**颗粒尺度**相近：`hf_energy` 差异 ≤ 20%（当前石材与雪地差 >2 倍）
2. 全局**色板收敛**：整帧 ≤ 48 个「主色」（16 色 × 3 阶），而不是现在的连续渐变
3. 每个材质**基色只允许 3 档明暗**（亮/中/暗），档与档之间是**硬边**，不做照片式连续过渡（这正是 HD-2D 的手绘感来源）

## 二、要产出的东西

新增 `spike/editor/MaterialForge.cs`（编辑器脚本，纯程序化，不依赖外部贴图），为下列每个材质生成 **Albedo + 粗糙度 + 法线（可选）** 三张 256×256 可平铺贴图，过滤模式 **Point**、无 mipmap 模糊：

| 材质 | 每米 texel | 色板（≤12 色） | 特征要求 |
|---|---|---|---|
| 教堂石材 `Stone` | 24–32 | 暖灰米 `#8C7C66/#A8967C/#C2B49A` 三阶 | 砌块缝隙 1 px 深线、**每块 ±8% 明度差**、四角 2 px 压暗（手绘倒角）、**不要照片噪点** |
| 屋顶石板 `Roof_Slate` | 24–32 | 冷灰 `#4A5058/#5E6670/#767F8A` | 叠瓦叠压 6–8 px 一片、接缝处 1 px 亮线 |
| 木门/长椅 `Wood` | 20–28 | `#4A3426/#6B4A32/#8A6D52` | 木纹 2–3 px 波浪线、**不跨块重复** |
| 雪地 `Snow` | 16–24 | `#DCE8F2/#EDF3F8/#F6FAFD`（**不许纯白**） | 大块 3 档明暗 + 少量 1 px 蓝灰斑点；sastrugi 走向跟随风向 |
| 裸岩 `Rock` | 20–28 | `#5F6E80/#77828F/#8B96A3` | 3 阶硬边明暗、阴面压 0.66（沿用现行规则） |
| 草/枯枝 `Grass` | 角色同源：1 px = 3 cm | `#3A342C/#57503F/#7A7358` | 极稀疏细线，**不要成片绿地毯** |
| 室内石材/石板 | 20–26 | 比室外「教堂石材」**整体暗 18%** | 同一套砌块逻辑，暖光下不发白 |

**统一规则（所有材质必须遵守）**
1. 色板量化：每个材质最终像素**最多 12 个不同 RGB 值**（生成时用 3 阶 ramp + 轻微 dither，dither 幅度 ≤ 0.03）
2. 硬边：阶与阶之间不做模糊过渡（`Point` 采样 + 3 档阶梯）
3. 颗粒：每张图必须有 **1 px 手绘抖动边**（轮廓/接缝处），禁止生成照片噪声
4. 可平铺：四边接缝处 `seam_max_grad ≤ 0.02`
5. 每米 texel 严格按表，不许多也不许少（用 `texels_per_meter` 常数控制，材质 `_BaseMap` 的 `tiling = 1 / (texel_per_meter × 贴图尺寸/米)`）

## 三、必须自己量测（贴到日志）

新增 `spike/tools/measure_style.py`（可用标准库 + `sips`，不要 pip 依赖）：
- `palette_size`：每个材质贴图里不同 RGB 的数量 → 必须 ≤ 12
- `texels_per_meter`：从材质 tiling 反算 → 必须落在上表区间
- `step_ratio`：三档明暗之间的边界像素占比（应有 8–25%，证明是硬边而不是渐变）
- `hf_energy`（复用 `measure_shot.py` 的定义）对 **石/雪/木/岩** 四张截图区域分别计算 → 两两差异 ≤ 20%
- 480×270 缩放后复算一次（`sips -z 270 480` 生成对比图 `Shots/style_480.png` 并放大回 1920×1080 存 `Shots/style_480_upscaled.png`）

打印一行：
`[STYLE] <material> palette=<n> texel_per_m=<f> step_ratio=<f> seam_grad=<f>`
最后一行：
`[STYLE_GATE] palette_ok=<bool> texel_ok=<bool> hf_spread=<f> pass=<bool>`

## 四、硬门槛

- 全部 7 个材质 `palette ≤ 12`、`texel_per_m` 在区间内、`seam_grad ≤ 0.02`、`step_ratio ∈ [0.08,0.25]`
- 四元素 `hf_spread ≤ 0.20`
- 整帧仍然满足现有美术判据：`snow_ratio ≥ 0.55`、`white_clip_ratio ≤ 0.05`、`magenta_px = 0`、`mountain_luma 0.42–0.60`
- 性能不退化：1920×1080 `fps ≥ 200`、`drawcall ≤ 330`
