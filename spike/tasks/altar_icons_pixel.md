# 任务：祭坛龛内圣像改成像素风（HD-2D 统一）

## 背景与决策
用户拍板：**选 2 —— 改成像素风圣像**。当前龛内三块圣像是写实油画风（内置 image_gen 出的），
近看精细但和整体像素风不是一个体系，缩到 480×270 会露出"照片贴进像素游戏"的违和感。

## 目标
三块圣像重做成**像素风手绘**：在 480×270 画面里能读出图形，在 1.2 m 近景里能看清像素格，
且和场景里其他像素元素的**颗粒尺度一致**（判据沿用项目老规矩：缩到 480×270 再放大，颗粒大小要一致）。

## 规格（硬性）
1. **尺寸与位置**：三块各 0.30 × 0.46 m，位置与现在完全一致（不要动模型几何、不要动金边）。
2. **分辨率**：每块按 **72 × 110 像素的"逻辑像素"** 绘制，再整数倍最近邻放大到 512 × 784 贴图；
   贴图内**不允许插值**（Unity 侧 Point filter、关闭 mipmap、aniso 1）。
3. **调色板**：每块 ≤ **12 色**，从项目现有色系里取：
   `#2A1E16` 深褐 / `#4A3526` 木褐 / `#7A6B5C` 石灰 / `#C9A227` 金 / `#E8DFCF` 米白 / `#A35A4A` 赭红 / `#3E4654` 冷灰；
   金色只能出现在圣光/头光/边框，占画面 ≤ 15%。
4. **明度**：整块 L* 25–70（暗底、中间调为主），不要大面积高光；顶部 1/3 允许放头光。
5. **构图**（三块要能区分，别三张一样）：
   - 左：圣母子（侧坐，头光为圆环，背景深褐 + 竖直金线）
   - 中：十字受难（十字居中、背景冷灰、下方有金线地脚）
   - 右：圣徒立像（正面站立、手持杖、背景赭红）
6. **风格**：硬边、无抗锯齿、无渐变（最多 3 级硬阶梯）、阴影用色块不用柔和过渡。
7. **不要**用写实照片/渲染图缩放，必须是逐像素绘制（程序化或手绘都行，但最终像素格必须是规整网格）。

## 交付
- 三张贴图：`spike/project/Assets/Art/Interior/Altar_Icons/icon_left.png / icon_mid.png / icon_right.png`（512×784，Point）。
- 材质：可复用现有 2 个材质槽（不要增加到第 3 个槽）。
- 日志 `[ALTAR_ICONS]`：`px_grid=72x110`、`palette_max`、`luma_min/luma_max`、`gold_pct`、`filter=point`。
- 截图：`altar_closeup.png`（场景内 1.2 m）+ `interior_inside.png`（原机位）+ 额外一张
  `altar_icons_480.png`：把近景缩到 480×270 后用最近邻放大 4 倍，用来判断像素颗粒是否统一。

## 验收门槛
1. 每块调色板 ≤ 12 色（写日志自证，我复核时会用 PIL 数唯一色数）。
2. 像素格规整：任意两个相邻像素块的边界必须落在 512/72 ≈ 7.11 px 的整数倍网格上
   （允许 ±1 px），可用自相关检测；`[ALTAR_ICONS] grid_ok=true`。
3. `L* 25–70`、`gold_pct ≤ 15%`、`filter=point`、`no_mipmap=true`。
4. 480×270 缩图里三块圣像仍能互相区分（我肉眼复核）。
5. `-demo-enter-church` 全绿、`tris ≤ 9000`、`materials ≤ 2`、`drawcall ≤ 260`、`fps ≥ 200`。

## 不做
- 不动模型几何、不动烛台/台布/十字、不动室外、不动图标墙与碰撞。
