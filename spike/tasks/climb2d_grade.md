# 任务：2D 攀爬配色与层次（五项，全在 2D 合成层）

## 现状（用户截图 1920×1080）
1. 整体**发米灰**：雪偏米黄、石与雪明度接近，整幅像蒙了土色滤镜，对比低
2. 顶部 y≈0–120 有一条**"融化滴状"灰带**（上坡面素材横向平铺露边）
3. **台地感**：雪面层层横叠，缺垂直落差；层间 y≈430 有硬直接缝
4. 同一棵树在 3–4 个尺度重复
5. 前景/背景层之间是硬边

## 要做的（按顺序）

### 1. 色校正（最见效）
- 雪：向 `#EDF3F8` 推，去掉米黄；阴影雪 `#CFDAE4`
- 石面：`b*` 从当前（约 +12）压到 **+6 ± 1**
- 整幅对比 +12%（可用曲线：暗部压到 0.06，亮部提到 0.94）
- 判据：`[GRADE] snow_b*=-2~+1 stone_b*=5~7 contrast_up=0.12`

### 2. 顶部灰带
- 裁掉或垂直翻转 `side_slope_up` 的平铺段，**不允许出现"滴状"边缘**；
- 顶边加 40 px 雾化过渡（到 `#DCE6EF`）

### 3. 垂直落差
- 在雪台之间插入 **3 处**垂直岩壁面（高 120–200 px，宽 200–400 px），
  用 `side_ground_cliff` 竖切；上缘带 20–30 px 雪檐、下缘 40 px 渐隐
- 判据：`[CLIFF2] drops=3 each_h=120–200`

### 4. 树的重复
- 用 `side_slope_trees` 切出 **3 个尺度变体**（高 90 / 150 / 240 px），
  每棵随机水平翻转 + 明度 ±8% + 位置抖动 ±12 px
- 判据：`[TREES] variants=3 flip=true luma_jitter=0.08`

### 5. 层间接缝
- 所有横向层之间做 **20 px 渐变融合**（下层的顶部 20 px 与上层底部做 alpha 过渡）
- 判据：`[SEAM] hard_lines=0`
