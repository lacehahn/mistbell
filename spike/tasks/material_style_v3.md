只做一件事：按用户拍板的三条改材质小样（雪/石/挡土墙），并修木门分缝。仍不铺开到屋顶/岩/草/室内。

用户原话：「雪保留这种感觉，2 保留，3 增加一点区别」——即：
1. 雪面**保持 v2 现在的样子**（方块感保留，不要改风格）
2. 石材**掺冷灰**（v2 全暖棕，冷调丢了）
3. 挡土墙/台阶**与教堂石材同族但要有区别**（不是同一套，也不是两套无关材质）

## 一、雪：不动视觉，只保数值

- 外观保持 v2（`Snow_Albedo.png` 原样）
- 但颗粒必须留在区间内：按**这套复量口径**（对 Albedo 做 GaussianBlur σ=1.0，取 |原−模糊| 均值 ÷255）
  目标 `Snow hf ∈ [0.010, 0.016]`

## 二、石材：掺冷灰（关键）

- 保持 3 阶硬边 + 1 px 灰缝 + 块边倒角 + 错缝（这些 v2 已达标，不要退化）
- **30–40% 的砌块**基色偏冷：从 `#8C7C66/#A8967C/#C2B49A` 之外，增加冷色块 `#7E848C / #9298A0 / #A9AEB4`
- 冷块与暖块要**随机分布**（不许按行/按列成带），同一行内相邻两块尽量不同温
- 总色数仍 **≤ 12**（暖 3 + 冷 3 + 灰缝/倒角 2 + 阴影 2 + 过渡 2）
- 整面平均色要**中性偏暖**：`mean_saturation` 下降 15–25%（相对 v2），但 `mean_hue` 不能被拉到冷侧

## 三、挡土墙 / 台阶：同族的"次级石材"

新增材质 `Stone_Sub`（台地挡土墙、石阶、围墙用），规则：
- 与教堂石材**同一套生成逻辑**（同灰缝 1 px、同倒角、同错缝），但参数不同：
  - 基色整体**暗 18–22%**，冷灰占比提到 **45–55%**
  - 砌块更大更扁：`18–26 texel 宽 × 10–14 texel 高`（教堂是 24×16）
  - `texel_per_m = 24`（教堂 28）
- 判据「同族但可区分」用 **`family_distance`** 量化：两材质在 480 缩图下**同一面墙区域的 ΔE(CIE76) ∈ [6, 18]**
  - < 6 → 太像，等于没区别
  - > 18 → 像两种石头，画面会花
- 台地石阶沿用 `Stone_Sub`，但顶面比侧面亮 8%（踩踏磨亮）

## 四、木门（v2 未读出来）

- 门板分缝：**2–3 条 1 px 竖向深缝**（`#2E2018`），把门分成 2–3 块板，缝必须**贯通整扇门**
- 木纹：每块板内 **3–5 px 宽**的深色纹线（`#3A281D`），沿板长方向、允许 1 px 抖动，密度不超过板宽的 25%
- 不许整片大理石纹

## 六、硬门槛

- 各材质 `palette ≤ 12`、`seam_grad ≤ 0.02`
- 石材 `cool_block_pct ∈ [0.30, 0.40]`、`Stone_Sub cool_block_pct ∈ [0.45, 0.55]`
- **`hf_spread ≤ 0.20`（σ=1.0 口径，用上面那套公式）**
- `family_distance ΔE ∈ [6, 18]`
- 木门 `wood_seams ∈ [2,3]`
- 整帧：`snow_ratio ≥ 0.55`、`white_clip_ratio ≤ 0.05`、`magenta_px = 0`、`mountain_luma 0.42–0.60`

注：`step_ratio` 这条旧判据与灰缝+倒角冲突（v2 实测 0.38–0.39），**改为只统计砌块内部像素**（排除 1 px 灰缝与 1 px 倒角），并把口径写进日志 `step_ratio_scope=block_interior`；该值目标 0.08–0.25。
