只做一件事：**把教堂墙面从"平铺贴图"改成"每面墙一张非平铺大贴图"**（UV 0–1 每面墙铺一次），这样才画得出参考图那种"墙顶厚雪 + 大块石 + 手绘边缘光"。屋顶/挡土墙/室内同步；雪/木/裸岩/枯草不动。

参考：`art-ref/ref-gergeti-hd2d.jpg`。用户选择："2"（非平铺方案）。

## 一、为什么会走到这一步

平铺贴图必须四边接缝，所以只能做"均匀小石块 + 每层一条雪线"，结果要么像乐高要么像斑马纹。参考图的质感来自**每面墙一张完整画面**：墙顶压着 2–4% 墙高的厚雪、石块从下往上尺寸递减、转角有大块隅石、朝上的边缘有暖色高光。

## 二、技术方案（按这个做，做不通再用备选）

**主方案：墙面 UV 重投影 + 图集**
1. 把教堂石材网格按**连通块**（每面墙一个）拆开，对每个连通块：
   - 取该块的主平面（法线方向），把顶点投影到平面 → 归一化到 **UV 0..1**（保持世界比例：`v` 按墙高、`u` 按墙宽）
   - 生成该面墙的 **1024×1024** 贴图（墙宽高比差异大时用 1024×512 或 512×1024）
2. 所有墙面贴图打进一张 **4096×4096 图集**，材质仍是 1 个（用 UV offset/scale 指向图集格子），**drawcall 不增加**
3. 贴图内容按世界尺度画（`texel_per_m` 由该面墙的尺寸推出来），保证石块实际尺寸一致

**备选（主方案 UV 重投影失败时）**：每面墙单独一个材质 + 单独贴图（墙面数 ≤ 8），材质 `_BaseMap` 各自 0–1。

## 三、每面墙贴图要画什么（照参考图）

1. **厚雪檐**：墙顶边缘 **2–4% 墙高**的厚雪带（不是细线），下缘不规则（±1–2% 墙高起伏，允许 3–5 处下垂），色 `#DCE7F2`，阴影侧 `#B9C8D8`
2. **石块**：宽 0.4–0.9 m、高 0.28–0.45 m；**从墙底到墙顶尺寸递减**（底部大、顶部小，模拟层高变化）；约 30% 块有 1–2 px 崩角
3. **灰缝**：1 px，色 = 块色 × 0.72，**不连续**（约 25% 位置两块直接相接）
4. **转角隅石**：墙的两侧边缘 8–12% 宽度内放大块石（0.7–0.9 m 高），并比中间亮一档
5. **暖色边缘光**：朝上的 1 px 边 + 受光侧（参考图是左上打光）提亮 18–22%，偏暖；背光侧压 12% 偏冷
6. **墙面下缘**：贴近地面 6–10% 高度处压暗（环境遮蔽），并把上一层雪/融化湿痕做出 1–2 px 深色带
7. 色数 ≤ 16（手绘感允许更多档），色相保持土黄 `b* +12 ~ +18`

## 四、必须量测并打印

```
[STYLE11] walls=<n> atlas=<px> per_wall_px=<min>-<max> texel_per_m=<min>-<max> drawcalls=<n>
[STYLE11_REPEAT] max_autocorr=<f>                 # 任一面墙自身 2 次平移后的相关系数，越低越没有平铺感（目标 ≤0.5）
[STYLE11_SNOW] snow_band_pct=<f> snow_centroid_v=<f>   # 雪带占墙高比例(目标 0.02–0.04)、雪的质心 v（应 >0.85，即贴墙顶）
[STYLE11_FRAME] church_L=<f> church_b=<f> roof_L=<f> sub_L=<f> interior_L=<f>
[STYLE11_GATE] repeat_ok=<bool> snow_ok=<bool> tone_ok=<bool> perf_ok=<bool> pass=<bool>
```

## 五、硬门槛

- `max_autocorr ≤ 0.5`（**关键**：非平铺的核心指标）
- `snow_band_pct ∈ [0.02, 0.04]`、`snow_centroid_v ≥ 0.85`（只在墙顶，不到处都是）
- 渲染后：`church_L ∈ [38, 42]`、`church_b ∈ [+12, +18]`、`roof_L ≤ church_L − 3.5`、`sub_L ∈ [10, 17]`、`interior_L ≤ church_L − 8`
- 性能：1920×1080 `fps ≥ 200`、`drawcall ≤ 330`（图集方案不应增加 drawcall）
- 显存：图集 ≤ 4096²，总量 ≤ 3 张图集
- 整帧：`snow_ratio ≥ 0.55`、`white_clip ≤ 0.05`、`magenta_px = 0`、`mountain_luma 0.42–0.60`
- 冻结：`Snow`、`Wood`、`Rock`、`Grass` 贴图 SHA 不变
