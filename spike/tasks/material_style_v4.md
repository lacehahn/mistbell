只做一件事：按**真实参考照片**重做教堂石材与挡土墙/台阶材质——**同一色相、不同深浅的灰**，去掉 v3 的暖冷混拼。雪/木不动，屋顶/裸岩/草暂不做。

参考图：`art-ref/ref-gergeti-real.jpg`（格鲁吉亚 Gergeti 三一教堂实拍）。

## 一、从参考图取到的色阶（我已实测，直接照用）

照片偏暗，取的是**相对关系**；落到我们场景时整体可以提亮 10–15%，但**必须保持同色相、同对比关系**：

- 教堂石墙 5 档（由暗到亮）：`#313234 / #4A4947 / #5A5653 / #65615E / #A7B0C1`
  → 实际使用去掉最后一档（那是高光/天空溢色），用 **4 档**：`#3A3A3C / #4C4A48 / #5C5855 / #6E6A66`，倒角高光另加 `#8B867F`（+12% 亮度）
- 挡土墙碎石 4 档：`#222224 / #373634 / #4A4845 / #5A5551`，**对比更强**（最暗到最亮差 ≥0.18 亮度）

关键：**没有色相变化**。允许 a/b 通道偏差极小的暖灰/冷灰（Lab |a|、|b| ≤ 3），但**绝对不允许** v3 那种暖棕块和蓝灰块并排。

## 二、教堂石材（`Stone`）

1. 色数 ≤ 10（4 档石 + 灰缝 + 倒角 + 2 档阴影）
2. 砌块尺寸：宽 **0.55–1.15 m**、高 **0.32–0.60 m**，每块尺寸随机 ±20%（不许整齐栅格）
3. 明度落档规则：每块从 4 档里随机取一档，但**相邻块明度差 ≤ 2 档**；同一行内**不许**出现"最暗/最亮交替"的棋盘纹
4. 灰缝 1 px，色 `#26262A`（比最暗档再暗 18%）；倒角 1 px，色 `+12%`
5. 表面只允许低频斑驳（每块内部明度起伏 ≤1 档），**不要高频噪点**
6. `texel_per_m = 28` 保持

## 三、挡土墙 / 台阶（`Stone_Sub`）

1. **碎石乱砌**，不是方正砌块：单块 **0.15–0.45 m**，行数 5–7 行，石块轮廓允许 1 px 不规则
2. 4 档明度，**对比更强**：最暗 `#222224` → 最亮 `#5A5551`，同层内明度差允许到 3 档（比教堂更乱）
3. 灰缝更宽一点（1–2 px），色 `#1A1A1C`
4. 顶部压顶石：一条 0.25 m 高的平整石板（亮一档），把墙体收边
5. `texel_per_m = 22`，尺寸比教堂粗一档
6. 与教堂 `Stone` 的 `ΔE ∈ [8, 18]`（比 v3 的 [6,18] 更强调"看得出是两种砌法"）

## 四、必须打印（可复现口径）

```
[STYLE4] <material> palette=<n> texel_per_m=<f> luma_steps=<n> chroma_ab_max=<f> block_w_m=<min>-<max> block_h_m=<min>-<max> size_cv=<f> checker_score=<f>
[STYLE4_HF] sigma=1.0 Stone=<f> Stone_Sub=<f> Wood=<f> Snow=<f> spread=<f>
[STYLE4_FAMILY] church_vs_sub ΔE=<f>
[STYLE4_GATE] palette_ok=<bool> mono_ok=<bool> checker_ok=<bool> size_ok=<bool> hf_ok=<bool> pass=<bool>
```

`checker_score` 定义：水平相邻的两块若「一块属于最暗档、另一块属于最亮档」，记一次；除以相邻对数。
`chroma_ab_max`：材质像素转 Lab 后 |a| 与 |b| 的最大值（灰度材质应 ≤3，倒角/灰缝可放宽到 6）。

## 五、硬门槛

- `palette ≤ 10`（Stone）/ `≤ 10`（Stone_Sub）
- `chroma_ab_max ≤ 6`（证明是单色相灰）
- `luma_steps ∈ [4,5]`
- **`checker_score ≤ 0.25`**（去掉棋盘感）
- `size_cv ≥ 0.15`（砌块尺寸要有变化）
- `Stone` 块尺寸、`Stone_Sub` 碎石尺寸按上面区间
- `ΔE(church, sub) ∈ [8,18]`
- `hf_spread ≤ 0.20`（σ=1.0 口径）
- 整帧：`snow_ratio ≥ 0.55`、`white_clip_ratio ≤ 0.05`、`magenta_px = 0`、`mountain_luma 0.42–0.60`
- 雪贴图 SHA-256 必须与 v3 一致（不许动）
