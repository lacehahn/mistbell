# 任务：围栏太密 / 颜色太亮 / 一处横穿路面，路面偏暗偏褐

## 现状（`cam_play_1080.png` 玩法机位，我复核）
1. **围栏密度翻倍**：立柱间距实测约 **1.1 m**（任务书要求 2.2 m），而且每侧有**两排**，
   整条路像高速公路护栏夹道；柱子是**亮黄褐**（不是要求的 `#4A3B2E` 深 walnut），
   在雪地里非常跳。
2. **弯道处有一道围栏横穿路面**：中景那个折角上，围栏线直接切过石板路（截图里很明显）。
3. **路面偏暗偏褐**：石板贴图的中调 `(124,112,100)` 在这个光照下读成"湿泥路"，
   与两侧纯白雪地反差过大；而且路缘有一圈**发黑的硬边**，像水泥路牙阴影。
4. 路面上那条白线已消除 ✓（上一轮做对了）。

## 要做的事

### 1. 围栏（最高优先）
- 立柱间距 **2.2 m ± 0.1**，**每侧只保留一排**（删掉靠内侧那排）；
- 立柱尺寸 **0.08 × 0.08 × 1.0 m**（现在是 0.10，略粗）；
- 颜色 `#4A3B2E`，顶面积雪 0.04 m（保持），但**受光面亮度压到 L\* ≤ 45**，
  不要出现亮黄褐；粗糙度 0.85、无高光；
- 修掉弯道处横穿路面的那段：围栏应沿路缘连续，**不得跨过路面**；
  日志 `[FENCE3] spacing= count= crossing=0`。

### 2. 路面
- 明度：整体 +8~10%（材质 `_BaseColor` 或贴图后处理均可），目标近景 `L* 52–58`（现在 ~45）；
- 色相：往冷走，`b* +5.5 → +2~+3`（把那份暖褐压掉）；
- 路缘：去掉那圈发黑硬边（是 Box 侧面/接缝阴影），让路面与雪地过渡自然，
  边缘加 6–8 cm 的雪压边（色 `#E8EFF6`）。

### 3. 雪地（随手）
- 现在太平（一整片纯白）：在中景加 2–3 处**低矮雪垄**（高 0.15–0.3 m、长 3–6 m、柔和起收），
  打破"白纸"感；不要加噪点，要体积。
